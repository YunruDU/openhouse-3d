關於這個 3D 地圖

這是個人製作的實驗性網站，不是中央研究院官方網站，也未經官方審核。 活動、報名與設施資訊可能不是最新，請以 中研院院區開放官方網站 為準。

怎麼做的

整個 3D 地圖由 Claude Opus 5.5（Anthropic，透過 Claude Code）協助開發，在一次對話中完成，約 3 小時。

  1. 從 OpenStreetMap 取得院區邊界、建築輪廓、樓層、道路與綠地，用真實高程資料做出後山地形。
  2. 參考公開授權的照片，逐棟調整外牆顏色、窗戶樣式與屋頂，做成微縮模型風格（陰影、景深、夜間燈光）。
  3. 把 2D 活動地圖的搜尋、篩選、報名狀態與設施圖層移植到 3D，並加上時間軸與導覽搖桿。
  4. 針對沒有獨立顯示卡的電腦做效能優化。

請注意

  • 建築外觀與高度、南部院區館舍位置、生態池形狀等為依公開資料推估，與實際可能不同。
  • 本站只適合電腦瀏覽；手機會自動轉到 2D 地圖。
  • 本站使用 Google Analytics 做匿名的瀏覽與點擊統計。
